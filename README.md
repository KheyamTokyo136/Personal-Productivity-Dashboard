# Flowly – Personal Productivity Dashboard

Flowly is a modern and responsive personal productivity dashboard built with React.js and Tailwind CSS. It is designed to help users organize their daily tasks, manage habits and routines, stay focused, and monitor their productivity from a single application.

## Features

- 📊 **Dashboard** – Provides an overview of daily tasks, habits, focus sessions, and productivity information.
- 📝 **Daily Planner** – Create, categorize, prioritize, complete, and delete daily tasks. Tasks can be assigned High, Medium, or Low priority.
- 🔥 **Habits & Routines** – Create and manage daily habits, mark habits as completed, and track habit streaks.
- ⏱️ **Focus Timer** – Includes Pomodoro-style focus sessions with work sessions, short breaks, and long breaks.
- 📈 **Analytics** – Displays productivity and activity information to help users understand their progress.
- ⚙️ **Settings** – Manage profile information and application preferences.
- 🌙 **Dark & Light Mode** – Switch between light and dark themes across the application.
- 💾 **LocalStorage** – Saves tasks, habits, theme preferences, and profile information directly in the browser.
- 📱 **Responsive Design** – The interface is designed to adapt to different screen sizes.

## Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- React Router
- Context API
- Lucide React
- LocalStorage
- Vite

## Project Purpose

Flowly was created as a practical frontend development project to strengthen my understanding of React.js and modern web development. The project focuses on component-based development, state management, routing, reusable components, browser storage, responsive UI design, and interactive user interfaces.

## Future Improvements

Future versions may include user authentication, cloud database integration, reminders and notifications, advanced analytics, calendar integration, drag-and-drop task management, and synchronization across multiple devices.
